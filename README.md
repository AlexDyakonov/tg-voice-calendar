# 🎤 Telegram Voice-to-Text Bot

Telegram бот для преобразования голосовых сообщений в текст с использованием Yandex SpeechKit API.

## 📋 Возможности

- 🎧 Распознавание голосовых сообщений Telegram
- 🎵 Обработка аудиофайлов
- 🌍 Поддержка русского языка
- ⚡ Быстрая обработка с помощью Yandex SpeechKit
- 📱 Удобный интерфейс с эмодзи и markdown

## 🚀 Установка и настройка

### 1. Клонирование репозитория
```bash
git clone <your-repo-url>
cd tg-voice-calendar
```

### 2. Создание виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:
```bash
# Telegram Bot Token (получите у @BotFather)
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# Yandex Cloud API Key (получите в консоли Yandex Cloud)
YANDEX_API_KEY=your_yandex_api_key_here

# Yandex Cloud Folder ID (ID папки в Yandex Cloud)
YANDEX_FOLDER_ID=your_yandex_folder_id_here
```

### 5. Получение необходимых ключей

#### Telegram Bot Token:
1. Найдите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

#### Yandex Cloud API:
1. Зарегистрируйтесь в [Yandex Cloud](https://cloud.yandex.ru/)
2. Создайте новый проект/папку
3. Перейдите в раздел "Сервисные аккаунты"
4. Создайте сервисный аккаунт с ролью `ai.speechkit-stt.user`
5. Создайте API-ключ для сервисного аккаунта
6. Скопируйте API-ключ и ID папки

## 📖 Использование

1. Запустите бота командой `/start`
2. Отправьте голосовое сообщение или аудиофайл
3. Получите текстовую расшифровку

### Команды бота:
- `/start` - Начать работу с ботом
- `/help` - Показать справку

## 🔧 Технические детали

### Зависимости:
- `python-telegram-bot` - Библиотека для работы с Telegram Bot API
- `requests` - HTTP-клиент для запросов к Yandex API
- `python-dotenv` - Загрузка переменных окружения
- `aiofiles` - Асинхронная работа с файлами
- `pydub` - Обработка аудиофайлов

### Ограничения:
- Максимальный размер аудиофайла: 1MB
- Поддерживаемый язык: Русский
- Формат голосовых сообщений: OGG Opus (стандарт Telegram)

## 🐛 Устранение неполадок

### Частые проблемы:

1. **Ошибка "TELEGRAM_BOT_TOKEN не установлен"**
   - Проверьте наличие файла `.env`
   - Убедитесь, что токен указан правильно

2. **Ошибка "YANDEX_API_KEY не установлен"**
   - Проверьте правильность API-ключа Yandex Cloud
   - Убедитесь, что сервисный аккаунт имеет необходимые права

3. **Бот не отвечает на сообщения**
   - Проверьте интернет-соединение
   - Убедитесь, что бот запущен и не завершился с ошибкой

4. **Ошибки распознавания речи**
   - Проверьте качество аудио
   - Убедитесь, что речь на русском языке
   - Проверьте размер файла (не более 1MB)
